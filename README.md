# Patient Questionnaire Data Analysis 

A data analysis project aimed at extracting insights from healthcare questionnaire data to better understand patient conditions.

## Overview
This project utilizes data processing techniques to clean, analyze, and visualize patient data, making complex healthcare information easy to interpret and utilize for reporting.

## Tech Stack
* **Language:** Python (Jupyter Notebook)
* **Libraries:** Pandas, NumPy, Scikit-learn

## Key Features
* **Data Processing:** Cleaning and preprocessing of raw IPD/OPD questionnaire data.
* **EDA & Sentiment Analysis:** Analyzing health trends and mapping sentiments (Positive/Neutral).
* **Data Visualizations:** Creating charts for better healthcare understanding.
